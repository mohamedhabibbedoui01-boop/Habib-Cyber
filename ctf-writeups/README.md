# CTF Write-ups

**Status:** Planned — write-up workspace.

## Objective
Publish clear explanations of CTF challenges that I have personally solved, focusing on methodology and lessons learned.

## Categories
- Web
- Forensics
- Cryptography
- Reverse Engineering
- Linux
- Networking
- Miscellaneous

## Write-up Template
```text
challenge-name/
├── README.md
├── screenshots/
└── artifacts/   # only files permitted by the event rules
```

Each write-up should include:
1. Event/platform and challenge category
2. Challenge description (summarized in my own words)
3. Initial observations
4. Investigation and reasoning
5. Tools and commands used
6. Solution explanation
7. Key takeaway and references

## Rules & Ethics
Respect event rules and embargoes. Do not publish flags, solutions, or challenge files when the competition prohibits disclosure. Remove tokens, credentials, and personal information from screenshots.

## Progress
Add a separate folder for each challenge after solving it and confirming that publication is permitted.
