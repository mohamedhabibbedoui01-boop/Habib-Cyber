# Digital Forensics Labs

**Status:** Planned — learning workspace.

## Objective
Record beginner-friendly digital-forensics exercises using synthetic or legally provided sample evidence.

## Planned Topics
- File metadata inspection
- Cryptographic hashes and integrity verification
- File-type identification
- Timeline basics
- Evidence handling and documentation
- Introductory memory and disk-forensics concepts

## Planned Structure
```text
digital-forensics-labs/
├── cases/
├── sample-evidence/
├── scripts/
├── reports/
└── README.md
```

## Case Report Template
- Case ID (non-sensitive training identifier)
- Objective and scope
- Evidence source and acquisition notes
- Hashes and integrity checks
- Tools and versions
- Steps and observations
- Findings, limitations, and conclusion

## Evidence Handling
Use training datasets or files you are authorized to examine. Preserve originals, work on copies, record hashes, and never publish private or personally identifying evidence.
