## How Each Project Will Be Documented

Every completed project should include:

1. **Purpose** — the problem the project addresses.
2. **Scope and safety** — systems, sample data, or lab environment used.
3. **Requirements** — tools, dependencies, and versions.
4. **Setup** — clear installation and execution instructions.
5. **Evidence** — screenshots, sample output, diagrams, or test results with sensitive data removed.
6. **Limitations** — known gaps and what could be improved.
7. **Lessons learned** — concepts and skills practised.
