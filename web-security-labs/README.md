# Web Security Labs

**Status:** Planned — learning workspace.

## Objective
Document foundational web-security concepts through intentionally vulnerable training applications and safe local labs.

## Planned Topics
- HTTP requests, responses, cookies, and sessions
- Authentication and access-control concepts
- SQL injection fundamentals and defensive parameterization
- Cross-site scripting (XSS) and output encoding
- Security misconfiguration
- File-upload validation
- OWASP Top 10 concepts and mitigations

## Planned Structure
```text
web-security-labs/
├── labs/
├── notes/
├── screenshots/
├── references/
└── README.md
```

## Lab Write-up Template
For each lab, record:
1. Learning objective and lab environment
2. Authorized scope and setup
3. Steps performed in the training environment
4. Observations and evidence
5. Root cause and security impact
6. Recommended mitigation
7. References and lessons learned

## Safety
Use intentionally vulnerable applications running locally or platforms that explicitly authorize training. Never test public websites or third-party systems without written permission.
